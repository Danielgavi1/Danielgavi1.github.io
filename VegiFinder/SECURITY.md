# Política de seguridad

## Versiones mantenidas

La rama `main` contiene la única versión mantenida de VegiFinder.

## Comunicar una vulnerabilidad

No publiques credenciales, datos personales ni detalles explotables en una incidencia pública. Envía un aviso privado al propietario del repositorio indicando:

- archivo o función afectada;
- pasos mínimos para reproducir el problema;
- impacto estimado;
- propuesta de corrección, si la tienes.

VegiFinder no necesita contraseñas, tokens, bases de datos ni archivos `.env` para funcionar. Cualquier secreto encontrado en el repositorio debe considerarse una incidencia.
